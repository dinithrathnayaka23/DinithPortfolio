# Dinith Portfolio

A modern personal portfolio website built to showcase my projects, technical skills, achievements, blog writing, and contact information in a polished and interactive experience.

## Overview

This portfolio is designed as a central place to present who I am as a developer and what I build. It highlights my journey in software engineering through:

* Featured projects across web, mobile, AI, and IoT
* Technical skills and tools
* Academic and extracurricular achievements
* Blog posts and technical writing
* Social and professional contact links

The site is built with a strong focus on clean UI, responsiveness, interactivity, and a modern visual experience.

---

## Features

* **Modern single-page portfolio experience**
* **Responsive design** for desktop, tablet, and mobile
* **Interactive UI sections** for projects, skills, achievements, and blogs
* **3D / visual enhancements** for a more engaging landing experience
* **Smooth scrolling and animated transitions**
* **Project showcase section** with tech stacks and links
* **Technical blog section** featuring published articles
* **Contact section** with social links and CV access

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/dinithrathnayaka23/DinithPortfolio.git
cd DinithPortfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the development server

```bash
npm run dev
```

### 4. Open in browser

Visit:

```bash
http://localhost:3000
```

---

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Starts the development server.

### `npm run build`

Builds the app for production.

### `npm run start`

Starts the production server after building the app.
